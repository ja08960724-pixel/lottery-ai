今彩539・順牌50期拖牌前三名分析系統 v1.0
Windows x64便攜版；不需要安裝Python。

【開始使用】
1. 先將整個ZIP解壓縮，保留EXE及_internal依賴資料夾在同一目錄。
2. 雙擊「今彩539拖牌分析.exe」或START.cmd。不要執行BUILD.cmd。
3. 一鍵更新獎號 → 一鍵分析 → 查看拖牌明細／匯出分析結果。
4. 需要網路下載最新獎號；下載失敗時可查閱本機資料或匯入CSV。
5. 不要只複製EXE，必須攜帶整個便攜資料夾。

【驗證範圍】
此ZIP僅在Windows x64建置、15項單元測試及封裝EXE自動測試全部成功後產生。
自動測試實際啟動封裝EXE，檢查中文含空白路徑、SQLite保存、CSV/HTML匯出、
Tcl/Tk視窗、歷史與明細、背景分析、關閉重啟、檔案釋放。
測試時PATH移除Python，EXE使用自帶執行環境；不是移除主機已安裝的Python。
Windows雲端主機是Windows Server；Windows 10/11實機與不同DPI人工操作尚待驗收。
完整自動測試報告見windows-smoke.json及unit-tests.txt。
不能將上述結果視為已完成所有Windows 10/11實機驗收。

【實作內容】
全繁體中文桌面介面，明亮色系、大字體、可縮放視窗、水平與垂直捲動表格。
採Python 3.11、標準函式庫Tkinter、SQLite及PyInstaller。
Tkinter替代建議的PySide6，減少依賴；程式不串接付費AI服務。
更新、匯入及分析使用單一背景執行緒，主介面輪詢接收結果。
SQLite連線於各操作完成即關閉，不留常駐背景程序。
關閉時取消後續請求並等待目前請求結束；單次網路逾時8秒、最多2次嘗試。
網路慢速串流或系統DNS逾時可能超過8秒；請勿直接終止寫入中的程序。

【原始碼與建置】
完整原始碼在GitHub lottery-ai儲存庫。
build_windows.ps1及BUILD.cmd只給開發人員；一般使用者不需要執行。
Windows Actions自動使用Python 3.11 x64及PyInstaller建置並驗證。

【封裝後使用】
解壓到可寫入資料夾，雙擊今彩539拖牌分析.exe或START.cmd。
一鍵更新獎號 → 一鍵分析 → 查看拖牌明細／匯出分析結果。
匯出CSV（UTF-8 BOM）與HTML位於exports。
查看歷史獎號可離線使用；離線重新分析明示本機資料截止日期，未宣稱已確認最新。
重新啟動保留歷史資料與快照；請重新分析以呈現目前結果。
CSV欄位：期別,日期,號碼1,號碼2,號碼3,號碼4,號碼5
日期為YYYY-MM-DD或YYYY/MM/DD。期別接受115000266或Biga六位115266。
CSV須為UTF-8或UTF-8 BOM。匯入錯誤會整批拒絕並保留既有資料。

【來源】
官方：https://api.taiwanlottery.com/TLCAPIWeB/Lottery/Daily539Result
使用month=YYYY-MM、pageNum=1、pageSize=50；每次更新近4個月。
為官網內部JSON端點，可能改版，程式會檢查content.daily539Res、期別日期及5碼。
指定Biga入口：https://biga.com.tw/99567/ 是查詢網頁，不是API。
已實際確認的今彩539專頁：
https://2019.biga.com.tw/ARCHIVE/DRAWDATA/PAGINATION/ZP/tw539resultlist?page=1
解析表格日期、期別、落球5碼及排序5碼，兩種號碼必須一致。
每次讀取第一頁（實測100筆），若網站縮減資料會顯示不足。
每次下載保留原始來源回應於data/sources，資料庫保留歷史，不隨更新刪除。
兩來源同一期日期與號碼一致才標示交叉驗證一致；其他標示單一來源。
衝突保留原值及來源觀測，標示衝突、排除涉及配對，不自行選邊。
目前衝突需人工比對原始來源與資料庫，沒有自動解除衝突功能。
若來源尚未發布最新一期，程式只分析已取得的截止資料，無法證明來源零延遲。

【統計】
取本機最新期及前49筆，共50筆；當期順牌由小到大。
每個起拖碼在任意位置出現均計入，僅計算窗口內兩端皆存在的有效相鄰期。
同年度連續期別且日期遞增才視為相鄰，缺期或衝突絕不跨接。
跨年期別重置時，兩端不能單獨證明上年度最後一期，採保守排除並警告。
若50筆包含缺期、衝突或未證實的跨年邊界，顯示「非完整50期分析」。
最新一期不作為起拖期。自拖照常計入。
C總和=5N、每個C≤N；N=0顯示無有效樣本。
排序：次數遞減、最近拖出日期遞減、號碼遞增。
同次數標記含前三名之外的所有候選，不代表預測能力差異。
歷史拖出比例=C/N×100%，不是下期中獎機率，不保證開出。
快照保存窗口、所有39碼計數、最後日期、前三名及逐筆配對。

【資料與錯誤】
data/history.sqlite3：歷史、來源觀測、更新紀錄、分析快照。
exports：報表；logs/app.log：啟動及執行例外。
資料位置預設為程式所在資料夾，可攜帶整個資料夾移動。
無法寫入時顯示原因並選擇資料位置；改選位置不自動搬移原資料。
改選位置記錄於LOCALAPPDATA\Lottery539Follower\location.json。
刪除此位置設定可回復預設相對路徑。備份時請在程式關閉後複製整個data資料夾。
不要同時開啟兩份指向同一資料位置的程式。
本包不含模擬資料庫；tests只在臨時資料夾建立合成資料。

【測試】
開發環境：python -m unittest discover -s tests -v。
封裝EXE：--self-test 測試報告路徑（僅開發驗收使用）。
合成測試資料僅在測試期間的TemporaryDirectory中建立並刪除，不寫入正式data。
手動實機待驗收項目詳WINDOWS_ACCEPTANCE.md。
