加州天天樂 Fantasy 5・順牌50期拖牌前三名分析系統 V1.0.0-CA
Windows 10／11 x64免安裝程式，不需要安裝Python，不需要付費AI API。

【啟動】
將整個ZIP解壓到可寫入資料夾，雙擊「加州天天樂拖牌分析.exe」或START.cmd。
請保留_internal資料夾，不能只複製EXE。一般使用者不需要BUILD.cmd。
本版只處理California Fantasy 5，01～39選5碼，不處理今彩539。
資料庫與設定獨立；請勿將今彩539的data覆蓋本版。

【操作】
一鍵更新獎號 → 一鍵分析 → 查看拖牌明細／匯出分析結果。
首次啟動隨附95期Biga真實資料（2026-08-01至2026-11-03、第012050期）。
隨附資料截止不代表今天已更新，請按「一鍵更新獎號」取得新資料。
開獎日期為America/Los_Angeles（美國加州）；分析／更新時間為Asia/Taipei。
不把加州開獎日直接當成台灣當日；跨年不重置加州官方期別。

【資料來源與限制】
Biga入口：https://biga.com.tw/99567/
已核對入口網頁JavaScript使用加州選項lotto=F及POST查詢：
https://biga.com.tw/99567/ajax_history_F.php
每次請求最近120日。驗證17欄資料、期別日期、排序與落球獎號一致。
加州官方最新期：https://www.calottery.com/en/draw-games/fantasy-5
官方頁面可能403、逾時或改版；失敗時仍保留Biga資料，明示單一來源。
官方可取得時僅核對該頁最新一期；不將其他期誤標為官方驗證。
Biga若暫時無法連線，仍可使用本機歷史資料與CSV匯入。
每次下載原始回應保存在data/sources，更新過程訊息保存在資料庫。
衝突保留原值，標示並排除涉及相鄰配對。衝突須人工核對，不自行選邊。
隨附95期全數標示單一來源；其最新一期日期、5碼已於製作時與官方網頁比對一致。

【計算】
最新已儲存一期的5碼由小到大作為5個起拖碼。
包含當期的最近50期，最多49組相鄰期配對；不足50期不分析。
起拖碼在歷史任意位置出現均計入；最新一期沒有下一期，不能作為有效起拖期。
相鄰須期別+1且加州日期+1天，缺期或衝突不跨接。
每個下一期5個獎號各累計1次，自拖照計。
依次數遞減、最近拖出日期遞減、號碼遞增取前三名；同次數均標註。
檢查C(a,b)≤N(a)、ΣC(a,b)=5×N(a)，N=0顯示無有效樣本。
歷史拖出比例=C/N×100%，不是下期中獎機率，不保證開出。
主畫面有合併去重號碼與共同候選數；所有號碼兩位數，以「、」分隔。

【資料保存與匯出】
data/history.sqlite3保存歷史、來源觀測、更新紀錄與每次分析快照。
exports保存UTF-8 BOM CSV與HTML，含前三名、完整計數、配對明細與來源。
logs/app.log記錄啟動及操作例外。更新失敗不刪除舊資料。
CSV欄位：期別,日期,號碼1,號碼2,號碼3,號碼4,號碼5
CSV日期須為加州日期YYYY-MM-DD，期別為官方數字期別（如12050或012050）。
不能匯入台灣民國期別（如115000266）。
預設資料位置是程式所在目錄；無法寫入時可選其他資料位置。
位置設定：LOCALAPPDATA\CaliforniaFantasy5Follower\location.json。
請等背景工作安全結束後備份／移動data。SQLite每次操作明確關閉連線。
